# Glossário

O leitor é dono de negócio, não marketeiro. Jargão técnico só em nota interna,
nunca em documento que sai.

| Não escrever | Escrever |
|---|---|
| lead | cliente que chega, quem procura |
| pipeline | propostas em aberto |
| SLA | tempo pra responder |
| ROI | retorno |
| CRM | sistema |
| funil | caminho até a compra |
| MQL | cliente que chega com perfil certo |
| CPL | custo por cliente que chega |
| criativo | anúncio, peça |
| copy | texto do anúncio |

Regra geral: se a palavra só existe dentro de agência, ela não sai.

## Exceção

Documento de canal e laudo de criativo são leitura interna. Ali o jargão é permitido e
até desejável, porque precisão vale mais que acessibilidade. A regra aperta quando o
documento vai pra cliente ou pra liderança fora de marketing. Cada template diz qual é
o caso dele.
